# ApacheNutchProject

This project explores the configuration and deployment of Apache Nutch, an open-source web crawler and search engine.
The following softwares are used in this project:
1) Apache Nutch - Version 0.9
2) Apache Tomcat - Version 8.5.95
3) JDK - Version 21.0.1
4) Cygwin 64 (Nutch was primarily designed and optmized for Linux systems.)

Link to download:
1) Apache Nutch 0.9 - https://archive.apache.org/dist/nutch/nutch-0.9.tar.gz
2) Apache Tomcat - https://archive.apache.org/dist/tomcat/tomcat-8/v8.5.95
3) JDK 21 - https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html
4) Cygwin 64 - https://www.cygwin.com/install.html

Setting Up:
On installing the given softwares, firstly we need to setup JAVA_HOME in user and system variables in the environment variables of your system.
